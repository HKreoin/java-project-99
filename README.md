Task Manager – система управления задачами, подобная http://www.redmine.org/. Она позволяет ставить задачи, назначать исполнителей и менять их статусы. Для работы с системой требуется регистрация и аутентификация.


## Интсрукция по локальному запуску
В терминале наберите команду:

`git clone https://github.com/HKreoin/java-project-99.git`

Для запуска наберите команду:

`make start`

Перейдите по адресу http://localhost:8080 в вашем браузере и войдите под следующим логином и паролем администратора:

Username: hexlet@example.com
Password: qwerty
